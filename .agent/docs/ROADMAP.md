# Дорожная карта развития xDrip Widget (Windows Desktop)

В данном документе собраны запланированные улучшения и функциональные расширения для десктопной версии виджета (C# WPF и Python).

---

## 1. Интеграция с Windows 10/11 и удобство на рабочем столе

- [x] **Автозапуск вместе с Windows (Run on Startup)**:
  - Добавить чекбокс в окно `Настройки` («Запускать при старте Windows»).
  - Реализация через ключ реестра `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
  - Автоматическое определение пути к текущему исполняемому файлу (`Assembly.GetExecutingAssembly().Location`).
- [x] **Прилипание к краям экрана (Screen Snapping / Docking)**:
  - При перетаскивании виджета ближе 15–20 px к границам экранов или панели задач — окно мягко «примагничивается».
  - Поддержка мультимониторных конфигураций и разных рабочих областей (`SystemParameters.WorkArea`).
- [ ] **Режим сквозного клика («Призрак» / Click-Through)**:
  - Пункт в контекстном меню для включения режима `WS_EX_TRANSPARENT` / `WS_EX_LAYERED`.
  - Позволяет виджету оставаться поверх всех окон, не мешая кликам мыши в играх или при работе с документами.
  - Отключение режима по горячей клавише или через иконку в трее.
- [ ] **Глобальная горячая клавиша (Global Hotkey)**:
  - Регистрация системного сочетания клавиш (например, `Ctrl + Alt + D`) через `RegisterHotKey`.
  - Мгновенный вызов диалога ввода терапии (`TreatmentDialog`) из любого активного приложения.

---

## 2. Безопасность и система тревог

- [ ] **Настраиваемые звуковые оповещения (Sound Alerts)**:
  - Воспроизведение звуковых сигналов при:
    - Падении сахара ниже порога гипогликемии (< 3.9 ммоль/л);
    - Резком падении по тренду (стрелки `SingleDown`, `DoubleDown`);
    - Превышении порога гипергликемии (> 10.0 / 14.0 ммоль/л).
  - Чекбоксы включения звука и регулятор громкости / выбор системного звука в окне настроек.
- [ ] **Индивидуальные пороги тревог в «Настройках»**:
  - Поля ввода персональных порогов (гипо, предупреждение, целевой диапазон, гипер) с сохранением в `config.ini`.
- [ ] **Визуальная пульсация карточки (Visual Alert)**:
  - Плавная анимация пульсации красной рамки виджета при глубокой гипогликемии или резком снижении глюкозы, заметная периферийным зрением.

---

## 3. Информативность и мониторинг данных

- [ ] **Отображение активного инсулина (IoB) и углеводов (CoB)**:
  - Серверная поддержка эндпоинта `/api/v1/current` уже верифицирована.
  - При наличии ненулевых значений (`iob > 0` или `cob > 0`) вывод аккуратного компактного блока: `IoB: 1.2 ед | CoB: 24 г`.
  - При нулевых значениях блок автоматически скрывается, сохраняя компактность интерфейса.
- [ ] **Интерактивный просмотр точек графика (Graph Tooltips)**:
  - Отображение всплывающей подсказки при наведении курсора на конкретную точку 4-часового графика: точное время замера, значение сахара и дельта.
- [ ] **Расчёт времени в целевом диапазоне (% TIR) за 4 часа**:
  - Анализ массива точек в истории и вывод компактного бейджа (например, `TIR: 88%`) в углу графика.

---

## 4. Визуальные режимы и стилистика

- [ ] **Эффект матового стекла Windows 10/11 (Acrylic Blur)**:
  - Подключение эффекта размытия подложки через Win32 API (`SetWindowCompositionAttribute` / `AccentState.ACCENT_ENABLE_BLURBEHIND` или `ACRYLICBLURBEHIND`).
  - Гармоничное сочетание тёмной темы карточки с полупрозрачным размытым рабочим столом.
- [ ] **Ультракомпактный режим («Мини-пилюля» / Compact Mode)**:
  - Переключение по двойному клику ЛКМ или через контекстное меню.
  - Сворачивание графика и второстепенных полей в ультраузкую полоску: `5.7 ↓ (-0.2)` размером ~120×36 px (удобно для фиксации над часами в углу экрана).
