## [Completed] Исследование и верификация передачи данных IoB и CoB на сервер (05.10.2026)
- **Анализ архитектуры бэкенда (`main.py`)**:
  - База данных SQLite содержит таблицу `devicestatus` с колонками `iob` (Insulin on Board), `cob` (Carbs on Board) и `battery`.
  - Эндпоинт `POST /api/v1/devicestatus[.json]` принимает стандартные пакеты статуса Nightscout (выгружаемые AAPS, OpenAPS, Loop, Trio).
  - Эндпоинт `GET /api/v1/current` агрегирует данные последнего замера сахара и актуального `devicestatus`, отдавая единый JSON с полями `mmol`, `mgdl`, `direction`, `delta`, `iob`, `cob`, `battery`, `minutes_ago`, `timestamp`.
- **Практическая верификация боевого сервера**:
  - Выполнен проверочный запрос к `GET /api/v1/current`.
  - Получен валидный ответ:
    `{"mmol":5.72,"mgdl":103.0,"direction":"SingleDown","delta":"-0.2","iob":0.0,"cob":0.0,"battery":83,"minutes_ago":0,"timestamp":1791193200}`
  - Зафиксировано: сервер полностью готов к трансляции IoB и CoB.
  - Причина текущих нулевых значений (`0.0`): автономное мобильное приложение xDrip+ передает только данные сенсора глюкозы и заряд батареи (`battery: 83`), но не рассчитывает профиль активного инсулина. При подключении AAPS (AndroidAPS) или помпы данные IoB/CoB появятся автоматически без доработки бэкенда.

## [Completed] Интеграция с Windows, Безопасность и Визуальные режимы (C# WPF) (06.10.2026)

### 1. Умное позиционирование диалоговых окон
- Диалоговые окна (`TreatmentDialog`, `SettingsDialog`, `TreatmentHistoryDialog`, `AboutDialog`) переведены на ручное позиционирование (`WindowStartupLocation="Manual"`).
- Метод `PositionDialogNearWidget(Window dlg)` рассчитывает координаты относительно виджета с автоматическим выбором стороны (справа/слева), учетом границ экрана `WorkingArea` и DPI-масштабирования монитора.

### 2. Интеграция с Windows 10/11 и удобство на рабочем столе (Раздел 1 Дорожной карты)
- **Автозапуск вместе с Windows**: чекбокс «Запускать при старте Windows» в «Настройках» с сохранением в ветку реестра `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
- **Магнитное прилипание к краям экрана (Screen Snapping)**: перехват `WM_MOVING` через `HwndSourceHook` — мягкое прилипание виджета в пределах 20 px к границам мониторов и панели задач.
- **Глобальная горячая клавиша (Global Hotkey)**: интерактивный ввод и захват сочетания клавиш в «Настройках» (по умолчанию `Ctrl+Alt+D`), регистрация через Win32 `RegisterHotKey` и вызов ввода терапии по `WM_HOTKEY` из любого активного приложения или игры.
- **Режим сквозного клика («Призрак» / Click-Through)**: включение прозрачности кликов `WS_EX_TRANSPARENT` через контекстное меню виджета и системный трей с всплывающей подсказкой BalloonTip.

### 3. Безопасность и система тревог (Раздел 2 Дорожной карты)
- **Индивидуальные пороги тревог в «Настройках»**: поля ввода порогов гипогликемии, гипергликемии, глубокой гипогликемии и критического гиперсахара с сохранением в `config.ini` (`threshold_low`, `threshold_high`, `threshold_urgent_low`, `threshold_urgent_high`).
- **Звуковые оповещения (Sound Alerts)**: нативные системные звуки Windows (`SystemSounds.Hand`, `SystemSounds.Exclamation`, `SystemSounds.Asterisk`) при выходе сахара за пороги и при резком снижении по тренду (`DoubleDown` ⇊ или `SingleDown` ↓ на сахаре < 6.0). Кнопка «🔊 Тест» в настройках и кулдаун повтора 20 минут.
- **Визуальная пульсация карточки (Visual Alert)**: плавная синусоидальная анимация подсветки рамки карточки (красная `#EF4444` при гипогликемии/крите, янтарная `#F59E0B` при резком падении), привлекающая периферийное зрение даже при отключенном звуке.

### 4. Визуальные режимы и стилистика (Раздел 4 Дорожной карты)
- **Эффект матового стекла (Acrylic Blur)**: аппаратное размытие фона рабочего стола сквозь тёмную подложку виджета через Win32 API `SetWindowCompositionAttribute` (`ACCENT_ENABLE_ACRYLICBLURBEHIND`). Управляется из «Настроек», контекстного меню и системного трея.
- **Ультракомпактный режим («Мини-пилюля» / Compact Mode)**: сворачивание виджета в узкую закругленную полоску 140×36 px с точкой AGP-статуса, сахаром со стрелкой и дельтой (`5.7 ↓ (-0.2)`). Мгновенное переключение по двойному клику ЛКМ, через меню виджета и трея.

### 5. Сборка и верификация
- Проект собран с помощью встроенного MSBuild v4.0.30319 (.NET Framework 4.5, C# 5). Размер исполняемого файла `dist/xDripWidget-CS.exe` составляет всего ~106 КБ.
