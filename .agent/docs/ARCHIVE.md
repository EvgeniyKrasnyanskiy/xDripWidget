# Архив выполненных задач и релизов

## [Completed] Релиз v1.9.0 (16.08.2026) — Адаптивный дизайн, 4-часовой график Android и улучшения Desktop

### 1. Android Widget
- **Адаптивный 4-часовой график глюкозы**:
  - При увеличении высоты виджета (`minHeight >= 90dp` — 4x2+) автоматически строится график сахара за 4 часа.
  - Отрисован полупрозрачный коридор целевой нормы (TIR 3.9–7.8 ммоль/л) с пунктирными границами.
  - Цветные маркеры точек, соединительные линии и шкала времени `-4ч`, `-2ч`, `сейчас`.
  - При компактной высоте (< 90dp) график скрывается (`View.GONE`).
- **Отзывчивая типографика и масштабирование**:
  - Динамическое увеличение шрифта сахара (`20sp` -> `26sp` -> `28sp`), дельты и времени при растягивании.
  - Пропорциональное масштабирование иконки батареи без перекрытия текстовых полей.
  - Жесткое ограничение `singleLine="true"` для предотвращения переноса дельты и времени на новые строки.
- **Точный опрос (1–5 мин) через AlarmManager**:
  - Обход 15-минутного ограничения WorkManager через `AlarmManager.setAndAllowWhileIdle()`.
  - Обработка `ACTION_BOOT_COMPLETED` для автозапуска таймеров после перезагрузки.
- **Сохранение скругления углов**:
  - Добавлен `widget_background.xml` с радиусом 14dp и `clipToOutline="true"`.

### 2. Desktop Widget (`widget.py`)
- **Коридор нормы TIR на графике**: полупрозрачный зеленый фон целевого диапазона 3.9–7.8 ммоль/л.
- **Адаптивная ширина графика**: `self.width() - 20` с динамической шкалой времени.
- **Безопасный путь к конфигурации**: поддержка `AppConfigLocation` и портативного режима.
- **Управление потоками `FetchWorker`**: безопасная отмена и очистка памяти при повторных опросах.

## [Completed] Разработка ультралегковесного нативного виджета на C# WPF (.NET) (05.10.2026)
- Создан автономный проект в папке `desktop_cs/` с компиляцией через встроенный `MSBuild.exe` (без внешних SDK).
- Размер исполняемого файла снижен с 36.2 МБ до **64 КБ** (в 550 раз легче).
- Аппаратно-ускоренная векторная отрисовка: скругленная карточка `#0F172A`, крупный сахар со стрелкой в цветах TIR/AGP, батарейка, дельта, 4-часовой график Sparkline с коридором нормы (3.9–7.8 ммоль/л).
- Устранена ошибка локализации парсинга `588,0` -> прямое преобразование без искажения запятых, вывод в инвариантной культуре.
- Полный редизайн контекстного меню WPF (удален белый системный отступ/колонка и белые разделители, применен темный стиль с синей подсветкой).
- Реализованы 4 модальных окна:
  - `TreatmentDialog`: ввод инсулина, углеводов, сахара и заметок с акцентными рамками в цветах AGP и отправка `POST /api/v1/treatments`.
  - `TreatmentHistoryDialog`: просмотр и удаление терапий через `DELETE /api/v1/treatments/{id}`.
  - `SettingsDialog`: настройки сервера, токена, слайдер прозрачности и интервал опроса в `config.ini`.
  - `AboutDialog`: информация о версии, репозитории и расшифровка диапазонов AGP.
- Динамическая капля крови в трее Windows и всплывающие тревоги (гипо/гипер).
- Скрипт сборки в один клик: `desktop_cs/build.bat` -> `dist/xDripWidget-CS.exe` (66 КБ).
- Диалог ввода терапии упрощен: убраны избыточные выпадающие списки и поля, события детектируются автоматически (`Meal Bolus`, `Carb Intake`, `Correction Bolus`, `Note`), добавлено управление с клавиатуры (`Enter` / `Esc`).
- Все диалоги (`TreatmentDialog`, `SettingsDialog`) переведены на автоматический расчет высоты `SizeToContent="Height"` для идеального отображения при любых масштабах экрана (DPI scaling 100%–175%) без обрезания кнопок.
- Добавлен надежный диалог подтверждения выхода из приложения ("Вы действительно хотите выйти из xDrip Widget?") с привязкой к окну (`owner`), перехватом Alt+F4 и выхода из трея.
