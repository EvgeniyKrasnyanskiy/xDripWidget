# План реализации изменений v1.7.0

## 1. Изменение шага ввода инсулина в Windows виджете
- **Файл**: `widget.py`
- Изменить шаг `QDoubleSpinBox` для инсулина (`self._insulin_spin`) с `1.0` на `0.1` (`setSingleStep(0.1)`).
- Шаг ввода углеводов остаётся без изменений (`1.0`).

## 2. Изменение размеров графических индикаторов батарейки
- **Android виджет (`WidgetUpdateWorker.kt`)**:
  - Уменьшить картинку батарейки в 1.5 раза по обеим сторонам (ширина и высота).
  - Размеры холста батарейки масштабируются в 1.5 раза (ширина 93px, высота 22px).
- **Windows виджет (`widget.py`)**:
  - Уменьшить ширину (длину) индикатора батарейки в 2 раза: `BAR_W` меняется с `72` на `36`. Высота остаётся прежней.

## 3. Поведение при ошибках сети (Network Retries)
- **Windows**: `QTimer` продолжает работать с установленным интервалом. На каждом тике таймера отправляется новый запрос к серверу.
- **Android**: `WidgetUpdateWorker` возвращает `Result.retry()`, запускающий повторные попытки с экспоненциальной задержкой в WorkManager.

## 4. Звуковые тревоги на Android
- **Пороги**:
  - Низкий сахар: по умолчанию `< 4.0` ммоль/л (настраивается).
  - Высокий сахар: по умолчанию `> 10.0` ммоль/л (настраивается).
- **Интервалы повтора тревог (Snooze)**:
  - При сохраняющемся низком сахаре: повтор каждые **30 минут** (по умолчанию, настраивается в UI).
  - При сохраняющемся высоком сахаре: повтор каждые **60 минут / 1 час** (по умолчанию, настраивается в UI).
  - При возврате сахара в норму таймеры откладывания сбрасываются.
- **Настройки UI & Пресеты**:
  - Переключатель включения тревог.
  - Поля ввода порогов низкого и высокого сахара.
  - Поля/слайдеры выбора интервала повтора (30 мин для Низкого, 60 мин для Высокого).
  - Выбор из 3 синтезированных мелодий (по умолчанию — **Siren**).
  - Слайдер громкости (0–100%) и кнопка проверки звука.
- **Синтез аудио**: `SoundGenerator.kt` создаёт 16-битный PCM звук через `AudioTrack` без внешних файлов.
- **Проверка тревог**: При каждом обновлении данных в `WidgetUpdateWorker.kt`.
