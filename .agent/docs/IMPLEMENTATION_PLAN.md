# План реализации изменений виджетов (Windows и Android) v1.6.0

## 1. Обновление цветовой схемы глюкозы и описаний
- **Цветовые пороги**:
  - `mmol <= 3.3` -> **Ярко-красный** (`#e74c3c` / `QColor("#e74c3c")`) — тяжелая гипогликемия.
  - `3.3 < mmol < 3.9` -> **Жёлтый** (`#f39c12` / `QColor("#f39c12")`) — легкая гипогликемия.
  - `3.9 <= mmol <= 7.8` -> **Зелёный** (`#27ae60` / `QColor("#27ae60")`) — целевая норма.
  - `7.8 < mmol < 10.0` -> **Жёлтый** (`#f39c12` / `QColor("#f39c12")`) — легкая гипергликемия.
  - `mmol >= 10.0` -> **Мягкий/менее насыщенный красный** (`#e57373` / `QColor("#e57373")`) — гипергликемия.
- **О документации**:
  - Добавить детальное описание цветовой схемы порогов глюкозы в окно «О программе» (PyQt6 в `widget.py` и Android в `MainActivity.kt`).
  - Добавить раздел «Цветовая схема глюкозы» в `README.md`.

## 2. Форматирование времени (с пробелом)
- Форматирование:
  - `< 60` минут -> `${m} м назад`
  - `60..1439` минут (1ч–23ч) -> `${m / 60} ч назад`
  - `>= 1440` минут (≥ 1д) -> `${m / 1440} д назад`
- Изменения в `widget.py` и `WidgetUpdateWorker.kt`.

## 3. Индикация свежести данных (Замена `Δ` на `🔄`)
- При свежих данных (Win: ≤ 1 мин, Android: ≤ 5 мин): перед дельтой отображается символ `Δ` (например, `Δ +0.2`).
- При устаревших данных (Win: > 1 мин, Android: > 5 мин): символ дельты меняется на `🔄` (круговые стрелки, например `🔄 +0.2`).

## 4. Графический индикатор батарейки в Android виджете
- Создать генерацию `Bitmap` горизонтальной батарейки в `WidgetUpdateWorker.kt` (аналогично рисования в Windows PyQt6):
  - Контур батарейки с носиком.
  - Цветная заливка прямоугольника в зависимости от уровня заряда (Зеленый >50%, Желтый 21-50%, Красный <=20%).
  - Рядом или внутри вывод текста с процентами заряда (например, `45%`).
- Разместить `ImageView` в XML разметке Android виджета.

## 5. Перекомпоновка Android-виджета 4x1 (2 строки)
- XML `widget_layout_4x1.xml`:
  - **Верхняя строка**: `tv_delta` (`Δ +0.2` или `🔄 +0.2` слева) | `tv_glucose` (`5.5 →` справа)
  - **Нижняя строка**: `iv_battery` / `tv_battery` (слева) | `tv_time` (`0 м назад` справа)
