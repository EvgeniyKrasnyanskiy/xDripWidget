# План реализации: Нативный легковесный виджет C# (.NET Framework 4.8 / WPF)

## Цель
Создать в отдельной директории `desktop_cs/` ультралёгкую и производительную нативную версию виджета на C# / WPF.
Размер выходного `.exe` файла — **до 300 КБ** (вместо 36 МБ Python-версии).
Запуск и компиляция осуществляются без установки сторонних SDK с помощью встроенного в Windows компилятора `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\MSBuild.exe`.
