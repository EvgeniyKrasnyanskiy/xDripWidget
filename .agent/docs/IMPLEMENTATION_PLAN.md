# План реализации v1.7.1: Фикс размера батарейки Android и 3-цикловая тревога (5 минут) с поддержкой тапа

## 1. Исправление визуального размера батарейки в Android виджете
- **Файл**: `widget_layout_4x1.xml`
- Изменить `iv_battery`:
  - `android:layout_width="wrap_content"`
  - `android:layout_height="wrap_content"`
  - Убрать `layout_weight="1"` у `iv_battery`, перенеся пружинный отступ или выравнивание на контейнер.
- В `WidgetUpdateWorker.kt`: `createBatteryBitmap` генерирует битмап размером 93x22 px (1.5x меньше).

## 2. Логика 3-цикловой тревоги (5 минут) и откладывания по тапу
- **Схема при выходе за пределы нормы** (низкий `< 4.0` или высокий `> 10.0`):
  - **Цикл повторов**: Максимум **3 раза** с интервалом в 1 минуту (1 мин звук — 1 мин пауза — 1 мин звук — 1 мин пауза — 1 мин звук = всего 5 минут).
  - **Автоматический переход в Snooze**: После завершения 3-го цикла тревога автоматически замолкает на полный интервал откладывания (**30 минут** для Low, **60 минут** для High).
  - **Тап по виджету в любой момент**:
    - Моментально глушит текущий звук.
    - Сбрасывает счетчик повторов.
    - Переводит тревогу в Snooze на **30 минут** (Low) или **60 минут** (High).
  - **Возврат сахара в норму (`4.0` – `10.0`)**:
    - Полный сброс счетчиков циклов и таймеров откладывания.

- Проверка синтаксиса и сборка Android APK (`./gradlew assembleDebug`).
- Сборка Windows EXE (`python -m PyInstaller xDripWidget.spec`).
