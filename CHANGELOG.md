# Changelog

Все заметные изменения в этом проекте документируются в данном файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект придерживается [Семантического версионирования](https://semver.org/lang/ru/).

## [Unreleased]

### Added
- Автономный модуль циклического логирования `Logger.cs` с записью подробного журнала работы виджета в `widget_cs.log` (ротация до 1 МБ, фиксация каждого опроса, времени задержки, статусов, ошибок и предупреждений).
- Раздельный выбор звуков тревог для низкого сахара (гипо), высокого сахара (гипер) и резкого падения в окне «Настройки»:
  - Выбор из стандартных сигналов Windows (`Hand`, `Exclamation`, `Asterisk`, `Beep`).
  - Поддержка выбора пользовательских аудиофайлов любых форматов (**`*.mp3`**, **`*.wav`**, **`*.wma`**, **`*.m4a`**, **`*.aac`**) через встроенный `System.Windows.Media.MediaPlayer` без сторонних зависимостей.
  - Кнопки предпрослушивания («▶») и выбора файла через проводник («📁») для каждого типа тревоги.
- Добавлены недостающие пункты «История / Удаление терапий», «Настройки…» и «О программе» в контекстное меню иконки системного трея (C#).
- Добавлен файл `CHANGELOG.md` для ведения истории релизов.

### Fixed
- Устранена проблема обрыва соединения с сервером при периодическом опросе (`ApiClient.cs`):
  - Таймаут запросов увеличен с 8 до 15 секунд, добавлен автоматический повтор запроса при таймауте (`TaskCanceledException`).
  - Внедрен 5-минутный порог отображения ошибки: при кратковременном сетевом сбое последнее значение сахара не затирается с экрана (ошибка выводится только если данных нет дольше 5 минут).
  - Добавлен заголовок `Connection: close` для предотвращения зависания неактивных сокетов в состоянии `CloseWait` и последующих ошибок сброса сокета (WinSock 10054 Connection Reset).
  - Внедрён механизм автоматического повтора (retry) с задержкой 500 мс при сетевых сбоях для всех сетевых вызовов (опрос данных, история, добавление и удаление терапий).
  - Настроен `ServicePointManager` (протоколы TLS 1.2/1.1 и лимит одновременных подключений).
- Исправлен захват фокуса клавиатуры в окне ввода терапии (`TreatmentDialog`): при вызове по глобальной горячей клавише окно принудительно переводится на передний план (`SetForegroundWindow`), активируется и курсор сразу выделяет поле ввода инсулина для мгновенного набора цифр.
- Исправлена привязка `config.ini`: `Config.cs` теперь автоматически находит конфигурационный файл в родительских каталогах и `dist/` при запуске из сборочных папок (`bin/Release`, `bin/Debug`), а также актуализирован адрес сервера в корневом файле конфигурации.
- Исправлен порядок завершения процесса в `build.bat`: `taskkill` выполняется до `MSBuild Rebuild`, предотвращая блокировку исполняемого файла при пересборке.
- Исправлена засветка кнопок при наведении курсора (`IsMouseOver`): внедрён единый тёмный `ControlTemplate` для `Button` в `App.xaml` с аккуратной подсветкой (+14% яркости без выцветания в системный белый цвет), текст остаётся высококонтрастным и легко читаемым на всех типах кнопок.
- Устранена засветка выделенной строки в контекстном меню системного трея и виджета: в `DarkThemeHelper.cs` и `MainWindow.xaml` резкий яркий фон заменён на мягкий тёмно-сланцевый цвет `#334155` с аккуратной рамкой `#475569`, обеспечивая отличную читаемость белого текста.

## [1.2.0] - 2026-10-07

### Added
- Ультракомпактный режим («Мини-пилюля» шириной 136 px) с вертикальным микро-индикатором батарейки (6×12 px).
- Визуальная пульсация рамки виджета при критическом разряде батареи смартфона/трансмиттера ≤ 5%.
- Механизм тихого пробуждения уже запущенного экземпляра виджета через `RegisterWindowMessage` / `PostMessage` без мерцания белых окон.
- Тёмное диалоговое окно подтверждения выхода (`ConfirmExitDialog`) с интеллектуальным позиционированием рядом с виджетом.
- Отображение галочек активных режимов в контекстном меню виджета и трея.
- Поддержка эффекта матового стекла (Acrylic Blur подложки Windows 10/11) через Win32 API.
- Глобальная настраиваемая горячая клавиша (`TreatmentHotkey`) для мгновенного вызова диалога ввода терапии из любого приложения.
- Режим «Призрак» (сквозной клик через окно / `WS_EX_TRANSPARENT`).
- Магнитное прилипание к границам экрана (Screen Snapping, порог 15-20 px) при перетаскивании виджета.
- Опция автозапуска при входе в Windows через системный реестр (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).
- Настраиваемые пороги сахара, звуковые и визуальные тревоги при гипо, гипергликемии и резком падении сахара.

### Fixed
- Устранён клиппинг полей ввода и оптимизирована геометрия окна настроек `SettingsDialog`.
- Исправлено отображение векторной иконки капли и убран лишний вертикальный скроллбар в `AboutDialog`.
- Устранён горизонтальный скроллбар в `TreatmentHistoryDialog` и переведены типы событий на русский язык.
- Исправлено выравнивание разделителей в контекстном меню `MainWindow.xaml`.
- Завершение запущенного экземпляра виджета в `build.bat` перед сборкой нового файла в папку `dist/`.

## [1.1.0] - 2026-10-05

### Added
- Нативная легковесная версия виджета на C# / WPF (.NET Framework 4.8 / net45) с размером `.exe` до 85 КБ.
- Векторная отрисовка 4-часового графика (Sparkline), дельты сахара, стрелок тренда и цветовых зон TIR в `GlucoseCanvas`.
- Диалог ввода терапий (инсулин/углеводы) и диалог истории с возможностью удаления ошибочных записей.
- Иконка системного трея с векторной генерацией капли крови и динамическим цветом по уровню сахара.
- Скрипт быстрой компиляции `desktop_cs/build.bat` через встроенный компилятор `MSBuild.exe`.
